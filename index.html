개인화 오퍼 증분효과 기반 타겟팅

인과추론 · 기여도 100%

문제
마케팅 오퍼는 보통 '반응할 확률이 높은 고객'에게 보냅니다. 그런데 그중 상당수는 오퍼가 없어도 어차피 구매할 고객이라, 그 혜택은 이미 일어날 일에 나가는 비용입니다. 반응 확률이 아니라 오퍼로 행동이 바뀌는 정도(증분효과)로 대상을 고르면 같은 예산으로 얼마나 더 벌 수 있는지 검증했습니다.
데이터
Hillstrom 이메일 캠페인 6.4만 명 — 남성 메일 / 여성 메일 / 미발송에 무작위 배정된 실제 캠페인
과정
증분효과 추정 4종 vs 반응 예측→Qini·증분 곡선 평가→손익 곡선→타겟 규모를 원(₩)으로 결정
개인별 처치효과는 관측이 불가능해 정확도·AUC를 쓸 수 없으므로 집단 단위 지표로 평가했고, 오퍼 단가와 증분 1건의 공헌이익으로 손익분기를 세워 몇 명에게 보낼지를 정했습니다.
결과
· 예산·인원을 고정하고 명단만 바꿨을 때 증분 이익 43% 증가 ($159 → $228)
· 전원 발송 −$125(적자) → 증분 상위 51%만 발송 +$397, 오퍼 비용 49% 절감하며 흑자 전환
· '확실 고객'으로 분류된 24.9%의 실제 증분은 −0.03%p — 전체 4분의 1에 나간 혜택이 낭비였음을 확인
진짜 결론
같은 데이터에서 오퍼 종류만 바꾸자 여성 메일에선 반응 예측보다 83% 더 벌었지만, 남성 메일에선 2% 차이에 그쳤습니다. 평균 효과가 손익분기를 넉넉히 넘으면 전원 발송이 답입니다. 기법의 가치는 상황에 따라 달라진다는 것을 데이터로 보였습니다.

SKALA · 5인 팀 · Graph·통합 담당 · GitHub

문제
새 기술을 검토할 때 개발사가 낸 수치만 보고 판단하면 결론이 좋은 쪽으로 기웁니다. KV 캐시 최적화 기술 2종(KIVI, InfiniGen)을 근거의 출처와 논조를 구분해 평가하는 시스템을 만들었습니다.
솔루션
논문 10편(184쪽)을 RAG로 검색하고 웹 검색을 더해 TRL·시장성·이해관계자·도메인 네 관점에서 병렬 평가한 뒤, 종합 보고서를 PDF로 내는 LangGraph 멀티에이전트
역할
· 근거마다 출처·쪽 번호·자체 보고/독립 출처·논조를 담는 공통 데이터 계약을 설계해 5명이 충돌 없이 병렬 개발
· 기준에 못 미친 관점만 1회 재조사하고, 그래도 부족하면 한계점으로 남기는 비용 상한 구조
· 없는 출처를 인용할 수 없도록 참고문헌 자동 생성, LLM 없이 규칙으로 도는 검수 루프
결과
전체 실행 약 2분, 근거 기반 보고서 17쪽 자동 생성. 팀원의 웹 검색이 동명 사이트를 근거로 가져와 TRL이 과대 평가된 문제를 찾아 정정했습니다.
